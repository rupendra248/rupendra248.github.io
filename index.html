01Statement

I work on wireless sensor networks that have to function without GPS, without mains power, and without much compute — and on the scheduling and learning systems that make constrained hardware useful.

My doctoral research addressed GPS-free localisation and energy-efficient routing in wireless sensor networks using machine learning and metaheuristic optimisation, with edge computing and IoT security as allied threads. Current work extends this to three-dimensional indoor localisation, metaheuristic optimisers, and federated learning across small edge clusters.
