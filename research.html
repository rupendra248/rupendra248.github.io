Research Projects & Initiatives

Highlighting core technical contributions in IoT systems, edge scheduling, and GPS-free sensor network optimisation.

ACM TECS 2024 WSN Optimisation Cluster Routing

Dynamic Cluster Head Selection in Wireless Sensor Networks

Objective: Enhance energy efficiency and network lifespan in Wireless Sensor Networks (WSNs) by introducing a dynamic cluster head selection algorithm based on node residual energy, distance, and density.

  • Key Contributions: Developed adaptive cluster head rotation strategy reducing energy drain during continuous sensing rounds. Evaluated across large-scale simulated topologies.
  • Advantages: Extends network longevity by over 24% compared to traditional LEACH protocols and mitigates premature node failures.
Collaborator: Prof. Abhishek Srivastava (IIT Indore)
Linux Kernel Edge Systems Asymmetric Multicore

Task Scheduling Algorithm for Asymmetric Multi-Core Edge Processors

Objective: Optimize task allocation in Linux on asymmetric multi-core edge devices (e.g. big.LITTLE architectures) by matching task priority with core computing performance.

  • Key Contributions: Built priority-aware task dispatch mechanism resolving sub-optimal Linux CFS assignment on heterogeneous cores.
  • Performance Improvement: Achieved up to 16% reduction in task execution time for critical real-time edge workloads.
Collaborator: Prof. Abhishek Srivastava (IIT Indore)
ACM TOSN 2025 GPS-Free Localisation Random Forest & Multilateration

A Hybrid Approach for Localisation of Sensor Nodes in Remote Locations

Objective: Provide accurate node position estimation in large-scale remote WSN deployments without relying on GPS receivers.

  • Methodology: Loosely couples Random Forest machine learning with multilateration algorithms using RSSI signals to achieve both high initial accuracy and iterative multi-hop coverage.
  • Validation: Demonstrated on simulated datasets and prototyped on physical sensor hardware.
Collaborators: Uttkarsh Aggarwal, Prof. Abhishek Srivastava
